## Wallpaper

`bliss.jpg`: 1920 × 1080 JPEG, 674,371 bytes, from [the image used by ShizukuIchi/winXP](https://i.imgur.com/Zk6TR5k.jpg), referenced in its [desktop implementation](https://github.com/ShizukuIchi/winXP/blob/master/src/WinXP/index.js).

The image is a widescreen copy of *Bliss*, the Windows XP wallpaper photographed by Charles O'Rear. The source does not provide a standalone open license for this image. Rights to the original photograph belong to Microsoft; this file is not represented as MIT-licensed or public-domain photography.
